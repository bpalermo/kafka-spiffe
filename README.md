# kafka-spiffe

SPIFFE mutual TLS for Apache Kafka 4.x brokers and clients: X.509-SVIDs from the SPIFFE Workload API, held in memory and rotated without restarts, peers verified by SPIFFE ID, and SPIFFE IDs as Kafka principals.

Nothing is implemented yet. The design is in [docs/design.md](docs/design.md), open for review.
